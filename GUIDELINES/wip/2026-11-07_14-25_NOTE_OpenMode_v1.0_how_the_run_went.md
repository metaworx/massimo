# NOTE OpenMode v1.0: how the run went

The owner's `EXEC++ OpenMode` ran Blocks 2 and 3 with D10-A and D11-A,
as recommended.

1. **D10: A.** An open server answers the range `localPeer` already took
   for the first owner: the box, RFC 1918, IPv6 unique local and
   link-local. Shared-address space such as `100.64.0.0/10`, which
   Tailscale uses, is not in it, so a Tailscale client reaches an open
   server only once it has a user or a token.
2. **D11: A.** The banner is not dismissible.
   The header has no `<hr>`: its rule is the bottom border of
   `header.top`, so the banner is the first element of `<main>`, under it.
3. **Block 3, the audit.** A refused write is counted with its address's
   refusals; a refused `GET` is not audited, as no refused `GET` is.
4. Otherwise as planned.
