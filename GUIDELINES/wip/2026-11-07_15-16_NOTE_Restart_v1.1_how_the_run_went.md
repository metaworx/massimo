# NOTE Restart v1.1: how the run went

How `PLAN++ Restart` carried out Blocks 5 to 7 of AP Restart v1.1, where
it went differently from the plan.

1. **`main` first.** Pull request 2's branch, from pull request 1's,
   merged `main` with AP CleanStop before Block 5, as the plan said; the
   CHANGELOG's Fixed section kept both bullets, and the Security section
   follows it.
2. **Block 5, `LoadFile`.** It now parses the file whole before it sets
   anything, as `ReloadFile` does: a parse error at a start sets nothing,
   where it used to set the lines before it. `serve` and the other
   commands stop on that error either way.
3. **Block 5, a name given twice.** Its first line wins on a reload, as
   at a start; otherwise every reload would have switched between the two.
4. **Block 5, the end-to-end test** goes through SIGHUP; the 5 s watch is
   tested on its own with a short interval, since a test of the built
   binary would wait ten seconds for it.
5. **Block 6** is tested without a store too: a stream ends with a new
   token.
6. **Windows** has no SIGHUP: there the watch is the only trigger, so a
   new `MASSIMO_API_TOKEN` applies 5 to 10 s after the file is saved.
7. **Seen once:** a full `make ui-test` had four skips, one test in its
   four cases, because discovery did not answer in time; the discovery
   and Cube tests run again passed without a skip.
