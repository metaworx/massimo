# NOTE DebNames v1.0: plus as a dot

A change to Block 1's step while the blocks stand, made in the merge of
main into `claude/deb-names` on 2026-11-10.

Main's "A package built between releases sorts after the one it follows"
(#171) puts git describe's part behind a `+`
(`0.13.0~alpha.2+1.g7d170c3`). GitHub keeps neither `~` nor `+` in an
asset's name, so `DEBFILE` writes both as dots:
`$(subst +,.,$(subst ~,.,$(DEBVER)))`.

- A release's file: `massimo_0.13.0.alpha.2_<arch>.deb`, as before.
- A rolling build's file: `massimo_0.13.0.alpha.2.1.g7d170c3_<arch>.deb`,
  the name `release/nightly`'s debs already carry; its control Version is
  `0.13.0~alpha.2+1.g7d170c3` (`dpkg-deb -f`).
- That GitHub writes `+` as a dot is inferred from its rule for
  non-alphanumeric characters, not yet seen on an asset: the first
  rolling build after the merge shows it, and `packaging/release-assets.sh`
  fails that build where it is otherwise.
