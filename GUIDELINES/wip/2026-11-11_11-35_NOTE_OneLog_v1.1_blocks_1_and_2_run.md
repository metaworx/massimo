# NOTE OneLog v1.1: blocks 1 and 2 run

How Blocks 1 and 2 of AP OneLog went where they differ from the plan,
on the branch of its pull request.

1. **The new file's first line is the file's own.**
   v1.1 had serve's `log_rotated` event write it.
   A test found other lines before it: between the writer's lock and the
   notice, any goroutine may write.
   `internal/logfile` now writes the first line itself, under its lock,
   in the file's format, as it writes the old file's last one;
   serve writes the rotation to stderr alone (a logger without the file)
   and to the store, as planned.
2. **launchd's stderr file is `/var/log/massimo-serve.stderr.log`,**
   not `serve.stderr.log` beside the log.
   `/var/log/massimo` is now the service user's, so that serve can rotate
   there, and launchd opens its file as root:
   one in a directory `_massimo` may write could be swapped for a link
   elsewhere.
   `/var/log` is root's; `massimo install` makes the file `root:admin` 0640.
3. **The Mac's log directory is `_massimo:admin` 0750,**
   D3-A for macOS: `admin` is its admin group,
   and a new file takes the directory's group there without set-group-id.
   An older release's `serve.log` is handed to that group, 0640.
4. **The unit writes the log through `ReadWritePaths=-/var/log/massimo`,**
   since `ProtectSystem=strict` leaves only the directories it names writable,
   and `LogsDirectory=` named it before.
5. **A specific setting wins wherever it comes from:**
   `MASSIMO_LOG_FILE_FORMAT` in the settings file wins over a `-log-format`
   flag, as each flag defaults to its variable.
6. **The conffile's removal names 0.14.0~alpha.2~,**
   since v0.14.0-alpha.1, released during the run, still ships
   `/etc/logrotate.d/massimo`.
7. **Left as they are:**
   Homebrew's `brew services` log (`var/log/massimo.log`, stderr, plain,
   not rotated), and the message for a box an older release took over
   (`chown -R _massimo:_massimo … /var/log/massimo`), which hands the
   directory back to the service's group until the next upgrade's postinst.

Verified for both blocks: `go test ./...`, `go test -race` for
`internal/logfile`, `internal/server` and `cmd/massimo`,
`go vet` for linux, windows and darwin, `make cross`, `make deb-test`,
`make deb-systemd-test` (the upgrade from v0.12.0-alpha.1 removes the
logrotate file and rotates the old plain `serve.log` at the start),
`make ui-test` (540 passed).
The Mac's template test and CI's Mac job run in CI only.
