# NOTE UiPolish v1.0: how the run went

How the run of [AP UiPolish v1.0](2026-11-15_00-17_AP_UiPolish_menus_header_and_copies.md)
went where it differed from the plan; its pull request is #272.

1. **Menus (Block 1)** are placed a frame after they open, once the
   other toggle listeners have filled them; a list that fits where the
   style sheet puts it stays there, so the Cube choice keeps its left
   edge.
2. **A failed retry counts (Block 2):** a request for System Info that
   fails while the certificate is being read counts as a try, so that
   the last one still says "could not be read".
3. **The facts stay beside the logo where they fit (Block 3):** a row of
   their own at all times would have cost a release's short version its
   place on the logo's baseline (D36-A). `fitFacts` measures them beside
   the logo each time and moves them to their row only where they do not
   fit there; a build's version fits beside the logo at 1100 and 1280 px,
   and takes its row on a phone, where the version now takes a line of
   its own above the time rather than being cut. A layout test of System
   settings and the baseline test follow, in a commit of their own and in
   Block 3's.
4. **Block 3 fixed after the merge of main:** the whole UI suite caught
   the version cut on a phone once. The drawing that replaces the logo's
   word keeps its width and changes its height, and `watchFacts` compared
   widths only; it compares the logo's size, fits again once the fonts
   have come, and starts from the header's own compacted state.
5. **A Cube's head (Block 4)** groups the sign, the name, the serial and
   the radio budget (`.cube-head-who`), so that the pill keeps the first
   line's last column; its grid needs `.panel.cube-panel`, as the panels'
   own flex rule comes later in the style sheet. The header shows no
   check before there is a Cube.
6. **Block 5 is two commits**, the API's `discovery_serial` and the
   page; the serial is only for a listener that answers discovery, the
   one on the Cube port. AP CopyFacts' proxies copy test clicks the
   address's icon, the line's last, since the serials come first.
7. **Main merged in twice**, with UpdateHistory and LogAlerts, then with
   RoomTile and EarlyHup; the second had one conflict, `placeMenu` and
   RoomTile's `menuArrows` both after `dropdown()`.
8. **A merge commit was made although its message check failed:** a `;`
   after the loop that waits for the signing agent ran the commit
   regardless. Its message was amended before the push; the commands
   chain the wait with `&&` since.
9. **The race run of the server package hit its 10 minutes** once, all
   packages at once on a loaded machine; alone it took under 5 minutes,
   and the whole list uncached passed after it.
10. **The guidelines check before the last push** named two GitHub merge
    commits that came with main, measured against the branch's upstream;
    the pull request's own commits passed the check against main.
11. **A docs line of Block 2** was 93 characters; Block 4's commit
    rewraps it.
12. **Verification:** `go test ./...`, `make race` (uncached),
    `make cross`, `gofmt`, the three `go vet`, `make ui-test` whole (820
    on the first pass, on the second merge with the fix), and
    `GUIDELINES/shared/tools/check`.
