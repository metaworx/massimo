## Where the run went differently from the plan

- **A fourth finding, `Dropdown` (`shared/menu.tsx`).** Block 6 added
  `arrows` and `focusCurrent` to its effect, which lists `[]`. The effect
  adds the toggle and key listeners once to the details, which is made
  once; listing the two properties would add the listeners again at a
  change and never take the old ones away. It got the same settlement as
  `Island` (D4-A): one `biome-ignore` comment with its reason. Its
  callers pass both as constants.
- **Eleven calls of the counter, not five.** The plan counted the
  Cubes' five at main after #331; Block 6 added the header's six. All
  follow `useLoad()`.
- **`ui/parts.js` passed over by both tests.** The bundle `make ui`
  makes lies beside the plain scripts and holds Preact's own code,
  `innerHTML` and `dangerouslySetInnerHTML` among it; it is not a file a
  person writes.
- **The contract's commit**, a third commit in Block 2 as the plan
  listed, raised the contract to v1.14.0 and wrote `AGENTS.md` and
  `GUIDELINES/README.md` again with `sync-docs.sh`.

## Checked

- Block 1: each rule fails on a planted file (a style sheet without its
  licence, a part without its copyright line, a header without a
  description, a wrong `@file` path, `innerHTML`, `outerHTML`,
  `insertAdjacentHTML`, `document.write`, `setAttribute("onclick")`,
  `data-i18n` and `dataset.i18n` in a part, `onclick=` in a partial); a
  ban named in a comment does not fail; the plants removed.
- Block 2: `make ui-check` fails on a hook after an early return and on
  `load.useLoad()` in a branch, the plant removed; it passes on the 51
  files in 25 ms after `tsc`. `make actionlint` passes.
- The gate: `make ui`, `MASSIMO_ENV_FILE=/dev/null go test ./...`,
  `gofmt -l .`, `go vet` for linux, windows and darwin, `make cross`:
  all pass.
- The UI tests of the touched parts, nine files (`test_parts_guard`,
  `test_cubes`, `test_cube_page`, `test_cube_problems`, `test_header`,
  `test_header_updates`, `test_home`, `test_server_sign`,
  `test_appearance`), both widths and languages:
  - first run, beside `go test ./...` in the background: 8 failed, all
    four cases of `test_cube_page_saves_as_system_settings_shows` and
    of `test_header_problems` ("nothing wrong: no problem pill"), and
    passed at the retry. The header test likely failed only because
    the Cube page's test stopped before it took its rename back; its
    screenshots were lost to the next run;

  - the nine on origin/main, the same ports, alone: 262 passed;
  - the nine on the branch again, alone: 262 passed.

  So the load of the parallel Go run is the likely cause, not the
  branch; that is not proven. CI's full suite is the next check.
